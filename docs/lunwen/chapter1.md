### 第1章 绪论

#### 1.1 课题背景及研究的目的和意义

随着全球人口的持续增长、耕地面积的日益减少以及极端气候频发，传统农业的生产模式正面临着前所未有的挑战。为了保障粮食安全、提高农业生产效率并实现资源的可持续利用，农业现代化与信息化已成为全球农业发展的必然趋势。近年来，中国政府连续出台了多项关于推进“智慧农业”与“数字乡村”建设的政策文件，明确提出要加快物联网、大数据、云计算和人工智能等新一代信息技术在农业生产经营领域的深度融合。在这一宏观背景下，设施农业，尤其是以无土栽培为代表的水培农业，因其具有节水、节肥、高产、不受土壤条件限制等显著优势，正逐渐成为现代设施农业的重要发展方向。

然而，尽管水培农业在理论和实验室环境中展现出巨大的潜力，但在实际的规模化生产与运营管理中，仍暴露出诸多痛点。首先，传统的水培温室管理高度依赖人工经验，工作人员需要频繁深入温室，手动读取温度、湿度、光照、营养液 EC（电导率）和 pH 值等环境指标。这种方式不仅耗费大量的人力成本，而且数据采集的频率低、精度差，难以满足现代水培作物对生长环境苛刻的精细化要求。其次，在环境调控与营养液配比方面，目前大多数农场仍采用半自动或手动的控制方式。例如，当温室温度过高或营养液浓度不足时，往往需要人工干预去开启风机或启动加液泵。这种滞后的响应机制极易导致作物生长受阻，甚至造成减产。再者，随着农场规模的扩大，温室数量、种植区划分以及作物批次的增加，使得数据的记录与追溯变得异常复杂。传统的纸质记录或简单的电子表格管理已经无法支撑现代农业对数据全生命周期管理、作物溯源以及数据驱动决策的需求。

为了解决上述问题，本课题旨在研究并设计开发一套“水培农植信息管理系统”。该系统的核心研究目的在于：利用物联网技术（如 MQTT 协议）实现温室环境数据的全天候、高并发、自动化采集；通过引入时序数据库（如 InfluxDB）解决海量环境数据的存储与实时查询问题；并在此基础上，构建一个智能化的控制策略引擎，能够根据预设的阈值、定时计划或作物生长的特定阶段，自动下发控制指令给底层执行器，实现气候调节与营养液配比的无人化作业。

本课题的研究具有重要的理论与实际意义。在理论层面，本课题探索了 Go 语言在构建高并发物联网后端架构中的应用，深入分析了关系型数据库（MySQL）与时序数据库（InfluxDB）在复杂农业业务场景下的双库协同设计模式，为后续类似物联网系统的架构设计提供了有价值的参考范例。在实际应用层面，本系统的成功研发与落地，能够将水培温室的管理者从繁重的重复性劳动中解放出来，极大地降低人力成本；同时，通过精准的自动化环境调控，能够有效提高作物的产量与品质，减少水肥资源的浪费，真正将“智慧农业”的理念转化为切实可见的经济效益与生态效益，展现了数字化技术赋能传统农业的巨大应用价值。

#### 1.2 国内外研究现状与分析

**1.2.1 国外研究现状**

设施农业与无土栽培技术的融合率先在欧洲、美国、日本等发达地区展开探索，早期应用形态多布局于建筑屋顶、立面及阳台等城市闲置空间。迄今为止，最早且最完善的种植体系是美国的”阳台农业种植体系”[26]，采用该体系的城市居民每日所需农产品的20%-30%来自自主种植[27]。在日本，政府与企业将设施化种植模块安装于建筑物外立面，使草坪、低矮灌木及果蔬作物覆盖于混凝土建筑表面，实现了农业生产与城市景观的有机结合[28]。德国则侧重拓宽型屋顶绿化种植，该方式具有重量轻、节约耗材的特点，同时有利于植物光能吸收、降低建筑室内温度并延长屋顶使用寿命[29]。在南美洲的巴西，一种由空心砖砌成的”绿草墙”广为流行，空心砖内部填充栽培基质，种子在适宜条件下萌发生长形成绿色墙体，兼具美化环境、净化空气、隔温隔热与降噪等多重功能。

在环境智能感知与控制技术方面，Rohim M D[30]设计了一种以Arduino微控制器为核心的桌面式种植监测系统，集成土壤湿度与光照强度传感器进行实时编码采集，当监测数据超出预设阈值时，系统通过液晶屏向使用者推送状态告警，有效应对了室内园艺环境管理的挑战。Nurminen A等[31]构建了归一化植被差异指数监测系统，创新性地将物联网与人工智能技术应用于种植环境的温度、湿度及光照强度分析，并搭建Web可视化界面供用户进行数据验证与决策辅助，显著提升了种植系统的智能化水平。Pennisi G等[32]聚焦于种植系统的能耗优化，对室内农业环境中发光二极管（LED）照明的生态效应进行了系统研究，采用国际参考生命周期数据系统（ILCD）方法完成了光照效果的环境影响评价。Wong C E等[33]通过精准调控光照质量与光照量实现了叶菜类作物产量与植物营养素含量的双提升，并针对不同作物品种及发育阶段制定差异化光配方，以实现产量最大化。Noh K[34]将设施农业的环境控制策略延伸至室内栽培场景，在办公与仓储空间中实现了温度、光周期、光谱及营养液供给的自动化调节，研究证实人类活动产生的CO₂浓度差异对植物生长具有显著影响，据此加大通风换气速率可进一步促进作物生长。Appolloni E[35]系统分析了LED光照配方及管理模式对不同作物次生代谢产物含量的调控效应。

从作物光环境调控的普遍规律来看，通过对光类型、光周期、光强度及光谱成分的系统分析，可为作物生长提出精准的调控建议，拓展设施水培农产品的品类范围[36]。在无土栽培技术领域，Uddin M R等[37]提出了一种现代改良版气培农业系统，利用超声波雾发生器将营养液雾化为微米级雾滴，使植物根系悬浮于雾态环境中高效吸收养分。超声波雾发生器以超音速频率振动产生微滴态水养分，大幅提升了根系对营养物质的吸收速率，辅以人工光照系统及温度、湿度、pH值的实时监测，为作物创造了最优的生长条件。Palande V等[38]构建了一套基于微控制器与传感器联动的自动化水培种植系统，该系统不依赖外部气候条件，用户仅需定植幼苗并设定初始参数，即可实现作物全生长周期的健康培育，将人为干预降至极低水平。Loconsole D[39]针对长叶莴苣的水培光管理需求，设计了一种基于LED的微生长光环境调控方案，通过提高红光比例并降低蓝光比例来优化光谱组成，缩短光周期以减少能耗，测试了昼夜光暗交替模式的效果并监测各循环阶段的能量消耗，最终以叶绿素a荧光等生理指标完成作物品质的综合评价。Park Y等[40]剖析了单源LED照明的光质、光量及日照时长对花卉与蔬菜作物生长发育特征的影响，通过改变LED单光源光谱组分来调节光环境，在作物产量与品质属性之间寻求最优平衡，进而获得理想的种植品质。Chen Z等[41]基于AHP-TOPSIS方法构建了城市设施化种植产品的多准则评价模型，据此梳理了该领域三大主要发展方向，为设施水培农产品的设计实践与方向决策提供了理论参考。

综合来看，国外对设施化种植系统的研究多集中于光效能与光照因素对作物生长的影响[42]，在保障产量提升的前提下追求能源消耗的最小化，以自动化手段驱动光照系统及环境控制装备的迭代升级，力求实现能耗与产量的均衡优化。然而，现有研究仍以单一硬件装置或光照调控为重心，将物联网数据采集、自动化控制策略与作物全生命周期管理深度集成的全栈式水培农植信息管理系统研发仍十分匮乏。

**1.2.2 国内研究现状**

在设施水培农植领域，国内早期多借鉴温室系统的顶层设计理念与国外无土栽培技术体系。受制于国内外技术标准与种植理念的差异，设施农业监控设备在起步阶段面临生产周期长、维护成本高、装置维修响应不及时等诸多困难。但随着传感器、无线通信、物联网及云计算等新兴技术的快速迭代，国内设施水培种植系统的研发进入了高速发展期。

在智能感知与自动控制方面，孙康等[43]提出了一种以CS32F103型控制器为核心的种植环境监控系统，通过多类作物生长传感器的数据采集与闭环反馈，实现了种植系统环境的智能化调控。何勉[44]设计了一种传感反馈控制与远端云平台协同的温室种植系统，其远程通信链路主要借助WiFi与ZigBee组网技术构建。杨勤等[45]运用Rhino三维软件完成了一种智能种植装置的设计，将SET分析法与TRIZ创新方法论相结合，为智能种植系统的工业设计提供了一条经过验证的创新路径。许国柱等[46]研制了一款以STM32芯片为主控的室内种植机构，通过传感采集模块与末端执行机构的协同配合，实现了作物生长环境的自动化调节；其内部栽培结构采用蜂窝状布局，同等容积下有效利用空间显著增大，对设施化种植装备的紧凑化设计具有积极推动作用。戎炯欣等[47]以正六边形蜂窝结构为内部栽培单元设计了一款种植装置，多个正六边形单元可自由叠加组合，使内部空间的利用更加灵活高效，大幅提升了空间利用率。

在环境调控与水培栽培管理方面，蒋薇[48]以园艺作物养护为研究对象，系统开展了微生长环境调控研究，依据季节变化的多样性特点，设计了适应多气候条件的栽培种植架，其自动控制系统采用模糊控制理论及仿真算法实现了栽培环境的系统调控。王星怡等[49]设计了一种集现代园艺、人工智能控制与水肥一体化技术于一体的立体栽培菌菜共生设备，具备节省空间、搬运便捷的特点，实现了菌类与叶菜类作物两相栽培的智能化管理。陶柳等[50]提出了一种支架与营养液循环系统一体化的”菱形”水培栽培系统，结构简洁高效、实用性强，其多级落差式营养液输送设计有效提升了系统内部的溶解氧含量，兼顾了空间适应性、绿化效果与作物生长的多重需求。魏冰青等[51]基于Kano-QFD模型研制了一种阳台水培装置，以用户需求为导向、以空间集约利用为核心设计约束，实现了水培种植效果的高效呈现。

在智能化管控平台方面，徐文栋等[52]针对室内环境特征与种植专业化需求，设计了一种以单片机为控制核心的种植管理装置，融合多种新型LED光源与传感器，实现了作物生长全过程的智能化管控。晋沅蓉[53]基于Pyramid框架，综合运用传感器、物联网、大数据与智能控制技术，研发了面向智能温棚的Web管理平台，通过模糊PID控制算法对作物生长环境进行自动调节，实现了设施化温棚的集约化智能管控。殷振新[54]以温室种植效率提升与管理难度降低为问题导向，以PLC为控制核心，设计了一套温室种植装置，实现了营养液输送、光照补充及物料传送的远程控制。

纵观国内设施水培种植系统的研究现状，领域内专业化的成套装备仍相对不足，现有系统的自动化与智能化水平参差不齐，仍属于智慧农业在水培细分领域的发展薄弱环节，亟需专业技术人员投入系统化、集成化的研发设计。尤其在水培农植管理软件系统层面，现有研究多聚焦于硬件装置的结构设计与单点控制功能的实现，缺乏面向规模化水培生产场景、涵盖物联网数据采集、智能策略调度与作物批次全生命周期管理的综合性后端信息管理系统。

**1.2.3 现有系统的不足与分析**

尽管国内外在设施农业与智能种植系统方面取得了丰硕的研究成果，但针对水培农植这一垂直细分领域的专业化、全栈式信息管理系统仍然较为匮乏。通过对现有研究的深入分析，当前系统主要存在以下不足：

1. **业务耦合度低，缺乏全生命周期管理**：现有系统大多停留在”数据监控”与”设备遥控”的浅层次应用层面，通常仅能展示当前环境参数并提供基础的开关控制。然而，水培农植的实际生产需将”环境数据”、”设备状态”、”控制策略”、”作物批次”及”营养配方”进行深度耦合。当前系统普遍缺乏针对水培作物从定植到采收全生命周期的批次化管理能力，以及与之动态绑定的营养液精准调配机制。

2. **底层架构对高并发与海量时序数据的支撑不足**：水培农植物联网系统具有典型的高频数据写入特征。一个中等规模的水培农场可部署上百个传感器通道，每秒持续产生大量遥测数据。然而，许多现有管理系统仍采用单一关系型数据库（如MySQL或SQL Server）承载所有数据存储，随着运行时间累积，单表数据量急剧膨胀，查询效率呈断崖式下降，难以支撑大规模水培场景下的高频数据并发写入与长周期跨度的时序数据分析需求。

3. **控制策略引擎僵化，缺乏灵活性**：现有自动控制系统的触发逻辑普遍较为简单，多为”单点阈值”控制（如温度超过30°C开启风机）。但在水培农植的实际运营中，往往需要复杂的”组合条件”触发（如温度大于28°C且湿度大于80%且持续时间超过5分钟），或基于”时间窗口”的周期性调度（如每周一、三、五早晨8点定时启动营养液循环）。现有系统的策略引擎在灵活性和可配置性方面存在明显不足，难以适配现代水培农场复杂多变的运营管理需求。

基于上述分析，本课题致力于设计并实现一套针对水培农植管理痛点深度定制的后端信息管理系统。在架构层面，采用Go语言结合MySQL与InfluxDB双数据库协同设计，彻底解决高并发时序数据的处理瓶颈；在业务层面，引入灵活的策略引擎与批次化作物管理模型，填补当前水培农植领域专业化管理系统的空白。

#### 1.3 论文主要工作

针对传统水培农业管理中的痛点以及现有农业物联网系统的不足，本课题基于现代软件工程方法和前后端分离架构，设计并实现了一套水培农植信息管理系统。论文的主要工作集中在系统后端的设计、物联网通信架构的搭建以及核心业务逻辑的实现上。具体工作内容包括以下几个方面：

1. **系统总体架构与双数据库方案设计**
   分析了系统面临的高并发设备接入、海量环境数据高频写入以及复杂业务关系管理等需求，设计了基于 Go 语言（Gin 框架）的后端服务架构。为解决传统关系型数据库在处理大规模时序数据时的性能瓶颈，创造性地引入了 MySQL 与 InfluxDB 双数据库协同架构。其中，MySQL 负责存储用户、设备、作物批次等结构化关系数据；InfluxDB 专用于高效存储与查询温度、湿度、pH 值等 14 项核心环境指标的时序遥测数据。

2. **物联网通信与设备接入模块的实现**
   构建了基于 MQTT 协议的物联网通信链路。通过引入 EMQX 作为消息中间件，实现了传感器设备与执行器设备的稳定接入。在后端服务中，设计了专用的 MQTT Ingress 模块，负责异步订阅、解析海量的设备上报消息（Telemetry 与 State），并对离线/在线状态进行心跳监控，确保了上下行通信的实时性与可靠性。

3. **智能化控制策略引擎的设计与开发**
   为了实现水培温室的自动化运行，设计并开发了一个灵活的控制策略引擎（Scheduler）。该引擎支持”阈值触发（Threshold）”和”定时调度（Schedule）”等多种策略模式。针对复杂的业务场景，引擎实现了组合条件判定、触发防抖（滞后值与时间窗口控制）、重试机制以及防止指令冲突的并发控制逻辑，能够自动向下游执行器通道下发精准的控制命令。同时，设计并实现了独立于策略引擎的气候多级调控调度器（Climate Profile Scheduler），基于带方向感知的多阶段滞回状态机实现温室环境的递进式自动调控。

4. **农作物批次与营养液管理模型的构建**
   针对水培农业的业务特性，设计了以”作物批次（Crop Batch）”为核心的生命周期管理模型。实现了作物从定植、营养生长期到采收阶段的全流程数据追踪，并创新性地将”营养配方（Nutrient Recipe）”与运行中的作物批次动态绑定。同时，构建了涵盖营养液罐实时监控、溶液更换记录与多离子成分检测的全链条营养液数据管理体系，为温室的水肥一体化管理提供了坚实的数据基础。

5. **命令下发与ACK回执闭环机制**
   构建了完整的控制命令全生命周期管理模块。设计并实现了命令状态机（PENDING→SENT→ACKED/FAILED）、同步/异步双模式下发以及基于MQTT回执的ACK追踪机制，确保了从策略决策到边缘执行的通信链路可靠性与可追溯性。

6. **系统安全与权限管理机制的实现**
   在系统安全性方面，基于 JWT（JSON Web Token）技术实现了无状态的用户身份认证机制。同时，设计了细粒度的 RBAC（基于角色的访问控制）权限模型，将系统用户划分为 ADMIN（管理员）、OPERATOR（操作员）和 VIEWER（观察员）三个层级，并在后端路由层通过自定义中间件实现了严格的接口鉴权与隔离。

7. **系统测试与性能调优**
   在系统开发完成后，搭建了基于 Docker Compose 的完整测试环境，对系统的各个核心模块进行了全面的功能测试。此外，针对高并发场景下的接口响应时间、时序数据的写入与查询效率进行了深度测试与分析，并根据测试结果在数据库索引、批量写入以及 SQL 语句优化等方面采取了一系列调优措施，验证了系统架构的高可用性与健壮性。
